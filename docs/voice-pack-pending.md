# 语音包遗留事项

## 无常用字的音（待定方案）

üe 的二声、三声（üé / üě）在普通话中没有对应的汉字——`yue` 音节实际只有一、四声
（约 / 月），二、三声无常用字可做同音替换。

- 影响行：lesson11 line10、line11（key `lesson11/üe_tone1`、`lesson11/üe_tone2`）。
- 现状（临时方案）：TTS 输入改用拼音拼写 `yué` / `yuě`，让引擎按音节+声调配读，
  见 `tools/gen_voice_content.py` 的 `TTS_TEXT_OVERRIDES` 注释。读音是否合格需抽听。
- 状态：待定方案，后续再定。可考虑的方向：含目标音节的多字词合成后裁剪、
  换支持 SSML 音素标注的合成通道。

## 其他待抽听项
