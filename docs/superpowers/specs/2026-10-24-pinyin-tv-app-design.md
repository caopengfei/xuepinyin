# 拼音乐园 · Android 拼音教学应用设计文档（TV 为主 + 横屏平板）

- 日期：2026-10-24
- 状态：设计已确认（调整记录见「决策记录」），待产出实施计划
- 项目：全新代码库 `D:\develop\src\rakor\xuepinyin`

## 1. 背景与目标

为小学一年级学生（6–7 岁）开发家庭拼音学习应用：以电视大屏为主战场（家长陪学、遥控器操作），同时支持横屏平板（触控操作）。内容严格依据现行统编版（部编版）语文一年级上册的汉语拼音部分：**3 个单元、13 课**。应用完全离线运行，无广告、无内购、无需登录。

v1 交付目标：完成「学一学 / 读一读 / 写一写 / 玩一玩」四模块 + 拼音总表 + 家长中心，配套预打包语音包，覆盖 TV 与横屏平板两种设备形态。

## 2. 设备与适配范围

| 设备形态 | 是否支持 | 输入方式 | 说明 |
|---|---|---|---|
| Android TV / 电视盒子 | ✅ 主战场 | 遥控器 D-pad、OK、返回 | LEANBACK_LAUNCHER 启动入口；焦点导航为第一公民 |
| Android 平板（横屏） | ✅ | 触控 | MAIN/LAUNCHER 启动入口；全应用锁定 `sensorLandscape`，忽略竖屏 |
| 手机 / 竖屏平板 | ❌ | — | 不做任何专门适配；Compact 宽度下居中信箱化呈现，不保证体验 |

要点：

- Manifest 同时声明 `MAIN/LAUNCHER` 与 `LEANBACK_LAUNCHER` 双入口；`uses-feature android.hardware.touchscreen` 设为 `required="false"`，保证可安装到无触控的 TV 设备。
- 运行时判定输入模式：`UiModeManager` 为 TELEVISION 或设备无触摸屏 → 遥控器焦点模式；否则 → 触控模式。
- 布局以横屏 Expanded 宽度（约 16:9 画幅）为唯一基准，TV 与平板共用页面结构，仅输入交互与字号档位不同。

## 4. 信息架构与页面流

```
首页课程地图（顶部导航：学一学 / 读一读 / 写一写 / 玩一玩 + 家长中心）
 ├─ 学一学 → 课程学习页（每课 5 步，线性推进）
 │    ① 认读字母（逐字母：大字 + 四线三格 + 发音 + 情境口诀）
 │    ② 声调练习（四声逐个听、跟读）
 │    ③ 笔顺演示（分笔动画；TV：OK 逐步，平板：点按/自动播放）
 │    ④ 拼读练习（本课字母参与的音节，声母蓝/韵母红分色）
 │    ⑤ 小结奖励（星星结算页）
 ├─ 读一读 → 模式选择（跟读课本 / 词句跟读）→ 跟读播放页
 ├─ 写一写 → 字母选择（按课分组）→ 笔顺演示页
 ├─ 玩一玩 → 游戏选择 → 摘糖果·找字母 / 声调跳跳
 ├─ 拼音总表（入口：首页「温故知新」卡片）→ 声母 / 韵母 / 整体认读 三标签点读
 └─ 家长中心 → 进度总览 / 设置 / 关于
```

课程学习页底部动作条为：听一听 / 跟读 / 上一课 / 下一课（**无儿歌入口**，儿歌已从 v1 砍除）。

星级标准：1★ 完成全部 5 步；2★ 步骤完成且跟读完成；3★ 在 2★ 基础上拼读练习全对。

## 5. 功能模块详述

### 5.1 学一学

- 首页「继续学习」直达当前进度课；课程卡按单元分组，已学/当前/未学三态。
- 5 步线性推进，步间有过渡音效与语音引导；任意步可返回上一步。
- 认读页字母逐个轮播（TV 左右键 / 平板左右滑动），情境口诀图与发音联动；声调练习支持四声切换听读。

### 5.2 读一读（v1 无儿歌，两个模式）

- 跟读课本：逐课内容跟读（字母 → 四声 → 口诀 → 拼读音节）。
- 词句跟读：与教材同步的拼音词、短句（如 bà ba、mā ma），大字幕逐行播放、逐句跟读。
- 播放页控制：播放/暂停、上一句/下一句、语速切换。

### 5.3 写一写

- 字母选择页按课分组；47 个字母（声母 23 + 韵母 24）全覆盖范写。
- 笔顺演示：四线三格 + 分笔路径动画（Canvas），每笔配口令（如 a：先左半圆，再竖弯）。
- TV 用 OK 键逐笔推进；平板直接点按「下一笔」或整段自动播放。

### 5.4 玩一玩（v1 两个游戏）

- 摘糖果·找字母：听发音，在 3–4 个糖果字母中选出正确的；答对摘下糖果。
- 声调跳跳：给出音节与目标，选择正确的标调结果（ā/á/ǎ/à）。
- 题目仅出自已学课程；答错语音鼓励 + 轻微抖动，不扣分不惩罚；连续答对有糖果收集反馈。

### 5.5 拼音总表

三标签页（声母 / 韵母 / 整体认读音节），沿用韵母红、声母蓝、整体认读绿配色；选中即发音。

### 5.6 家长中心

- 进度总览：每课星级、四模块使用时长、本周学习日历。
- 设置：语音语速（0.8 / 1.0 / 1.2）、音量、护眼提醒（默认每 20 分钟提示休息，可关闭）。
- 关于：版本信息、教材依据声明。

## 6. 视觉与交互规范（糖果乐园 · 方案 A）

- 色板：底色奶油 `#FFF6E9`；主色珊瑚红 `#FF6B6B`；辅色柠檬黄 `#FFC94D`、薄荷绿 `#43C8B0`、天空蓝 `#54A0FF`、葡萄紫 `#9B7EDE`；文字深可可 `#4A3B32`。
- 拼音教学配色惯例：韵母红、声母蓝、整体认读绿。
- 卡片：大圆角、粗描边（深可可）、贴纸感硬阴影；吉祥物熊猫「奇奇」贯穿引导；奖励用星星 + 糖果。
- 输入模式规范：
  - 遥控器焦点态：卡片放大 1.06 + 深色描边 + 硬阴影 + 焦点切换音效；每页声明默认焦点，焦点丢失可恢复。
  - 触控态：按压涟漪、点按即触发；Compose 焦点视觉仅在键盘/手柄触发时出现，触控不显示焦点框。
- 字号档位：TV 基准（正文 ≥ 28sp 等效，字母展示超大）；平板横屏整体下调一档（正文 ≥ 20sp）。触控与焦点目标均 ≥ 48dp。
- 动效克制：焦点/答对/奖励有动效，遵循系统「减弱动态效果」设置。

## 7. 技术架构

- Kotlin 2.x；Jetpack Compose for TV（`androidx.tv` Material3：TvLazyColumn/Row、Card）+ Material3 组件；单 Activity + Navigation Compose。
- `minSdk 21`、`compile/target 36`（2026-09 工具链：Gradle 9.5.1 / AGP 8.13.2 / Kotlin 2.2.21，适配本机 JDK 25）；全应用 `sensorLandscape`。
- 单模块内分包：
  - `ui/`：theme（糖果乐园 Design Token）、screens（home / lesson / read / write / play / table / parent / reward）、navigation、focus 工具、InputMode 适配。
  - `domain/`：课程模型、进度状态机、游戏出题器、拼音规则（标调位置、ü 去点）。
  - `data/`：AssetsCourseRepository（lessons.json）、ProgressRepository（DataStore）、SettingsRepository。
  - `audio/`：VoicePackPlayer（播放队列、打断、语速、缺失降级）。
- 设备适配：InputMode（Focus / Touch）由系统判定注入；WindowSizeClass 仅用于区分 Expanded（所有支持设备）与 Compact（信箱化兜底）。

## 8. 数据与内容模型

- `assets/lessons.json`：13 课结构。每字母字段：pinyin、type（single_final / compound_final / initial / special）、tones（四声形）、口诀、情境 emoji 与例字、笔顺步骤（分段路径指令数组）、标调规则位；每课：拼读音节表、步骤配置、挂载的整体认读音节。
- 笔顺数据：47 个字母手工定义分笔路径（起点、方向、弧线参数），Canvas 绘制。
- 进度（DataStore + JSON 序列化）：每课 `steps{view, tones, stroke, syllable}`、stars、跟读完成标记、游戏成绩、累计使用时长；全局设置项。
- 语音台词 key 规则（与语音包 manifest 一致）：`lesson{N}/{letter}_{tone}`、`lesson{N}/mnemonic_{letter}`、`read/{mode}/{lineId}`、`common/{uiInstruction}`、`game/{event}`、`reward/{level}`。

## 9. 语音包管线（voice-pack-generation）

- 台词清单：47 字母 × 四声读音、每字母口诀与情境词、拼读音节、词句跟读内容、UI 指令语音（「按 OK 键试试吧」等）、游戏反馈与奖励语。**不含儿歌**（已砍除）。
- 产出：逐行单声道 Opus + `manifest.json`，置于 `assets/voicepack/`；TV 与平板共用。
- 启动校验（debug 断言）：台词 key 与 manifest 全覆盖；正式包运行时缺失则静音跳过，家长中心红点提示。

## 10. 错误处理与边界

- 语音缺失：静默跳过并提示，不阻塞流程推进。
- 进度文件损坏：仅重置该课进度并提示，不清空整体进度。
- Opus 解码失败（老旧 API 21/22 盒子）：首次播放失败后提示，语音包管线支持整体转码为 AAC 重新打包作为兜底。
- 焦点丢失：每页面通过 focusRequester 声明默认焦点。
- 护眼提醒：到时弹层，任意按键或点按继续，可在家长中心关闭。

## 11. 测试策略

- 单元测试：进度状态机（步骤 → 星级映射）；课程数据完整性（13 课、47 字母、类型、整体认读挂载、语音 manifest 全覆盖）；出题器（仅已学内容、不重复、干扰项合理）；拼音规则（标调位置、ü 去点）。
- Compose UI 测试：首页四模块导航、课程 5 步推进与返回、游戏判定与结算、设置修改生效；分别以 TV（1080p）与平板横屏两套配置运行。
- 手动验收清单：TV 模拟器 + 真实遥控器全流程；平板横屏模拟器触控全流程；API 21/22 老盒子冒烟（含 Opus 播放验证）。

## 12. v1 范围与非目标

范围：四模块 + 拼音总表 + 家长中心 + 预打包语音包 + TV/横屏平板适配。

非目标（后续迭代）：手机与竖屏适配、配乐儿歌（v1 已砍）、录音跟读打分（TV 麦克风不可靠）、多孩子档案、云端同步、任何联网内容。
